Activer la double authentification

Obligatoire pour tous les comptes. À chaque connexion, un code à 6 chiffres vous sera demandé en plus.

1Installez une application d'authentification sur votre téléphone, par exemple Google Authenticator ou Microsoft Authenticator.
2Scannez ce code avec l'application.

Impossible de scanner ? Saisissez cette clé dans l'application : JBSW Y3DP EHPK 3PXP (exemple)

Compte partagé. Chaque personne autorisée du ministère scanne ce même code maintenant, avec son propre téléphone. Il ne sera plus affiché.
3Saisissez le code affiché par l'application.
